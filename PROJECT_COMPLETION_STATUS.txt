🎯 下一步操作

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  1. 克隆原项目源码
     cd xxgkami-enhanced/backend
     git clone https://github.com/xiaoxiaoguai-yyds/xxgkami-pro.git

  2. 创建密码学类 (从 PROJECT_STATUS.md 复制代码)
     mkdir -p src/main/java/org/xxg/backend/backend/crypto
     # 创建 PasswordEncoder.java 和 EncryptionUtil.java

  3. 添加 Maven 依赖 (参考 PROJECT_STATUS.md 第 98-128 行)

  4. 配置环境变量
     cp .env.example .env
     vim .env  # 修改所有密码和密钥

  5. 一键部署
     chmod +x install-enhanced.sh
     sudo ./install-enhanced.sh
